## 🚀 How to Use CanopyOps

Once you open the software, you can begin managing your cultivation operations through the main dashboard. 

### Starting a Crop Plan
Navigate to the "Crop Plans" tab to enter details about your current harvest. You can input strain information, planting dates, and expected harvest timelines. The system uses these inputs to build a structured schedule for your specific needs.

### Tracking Diagnostics
Use the "Diagnostics" section to log observations about your plants. If you notice discoloration, leaf spotting, or growth delays, input these observations into the system. The software compares these inputs against known cultivation patterns to provide recommendations for adjustments.

### Managing Harvest Records
The "Harvest Review" tool allows you to log final weights, drying times, and quality metrics. Accurate record-keeping ensures that you can review your performance for future cycles.

## 🔍 Understanding Features
